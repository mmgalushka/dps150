# Code of conduct

We want dps150 to be a friendly place to learn and build. This is a short code in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/); replace it with the full text if the project grows.

**Do**
- Be kind and assume good faith. Beginners and experts are both welcome here.
- Keep feedback about the work, not the person.
- Say what you tried and what happened, so others can help.

**Do not**
- Harass, insult or discriminate against anyone.
- Publish other people's private information.
- Post spam or off-topic promotion.

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them. To report a problem, write to the maintainer at the address on their GitHub profile.
